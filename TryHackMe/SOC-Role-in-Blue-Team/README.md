# SOC Role in Blue Team

## Overview 
This TryHackMe room introduced the role of a Security Operations Center (SOC)
This room helped me understand how SOC teams contribute to an organization's defensive security operations and how security analysts monitor and respond to security related activity.

## Key Concepts Learned
- Security Operations Center (SOC)
- Blue Team operations
- Security monitoring
- Security alert handling
- Role of a SOC Analyst
- Defensive Security operations

## SOC Analyst Responsibilities 
A SOC Analyst is involved in monitoring security activity, reviewing alerts, investigating suspicious events and supporting the organization's security operations.
The SOC works as part of defensive security team to identify and investigate potential security incidents

## What I Learned
Through this room, I developed a foundational understanding of:

- How a SOC operates within a Blue Team
- The purpose of security monitoring
- The role of analysis in identifying suspicious activity
- The importance of investigating and documenting security alerts
- How defensive security team contributes to protecting an organization
